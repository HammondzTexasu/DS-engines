# Apply Art Engine direction

Use the generated Art Engine prompt whenever the task designs, implements, refines, or evaluates user interface work.

1. Read the full generated prompt before making visual decisions.
2. Solve product requirements, usability, and accessibility first.
3. Apply the profile, dimensions, rules, anti-rules, and heuristics consistently rather than copying one visual motif everywhere.
4. Treat a dimension's reference override as canonical only within the scope stated by its note; do not generalize it into a component or token system.
5. Use the project's Color Engine and Typo Engine outputs when present. Do not invent competing token systems.
6. When reviewing existing UI, compare it against the same prompt, report concrete drift, and suggest the smallest useful correction.
7. If the prompt conflicts with an explicit user requirement, explain the conflict and follow the user's current intent.
8. Do not modify the Art Engine config during ordinary UI work unless the user asks to tune or recalibrate the profile.
