# Review output against Art Engine

Use the generated `reviewPrompt` from `generateSystem()` and attach the implementation, screenshot, or design description to review.

## Review contract

1. Report concrete violations before subjective suggestions.
2. Separate:
   - product/usability problems,
   - color/typography token violations,
   - art-direction drift.
3. Point to the exact rule, anti-rule, heuristic, or strong axis involved.
4. Prefer the smallest correction that restores the profile.
5. Do not redesign merely to express personal taste.
6. If profile instructions conflict with usability or accessibility, state the conflict and prioritize usability/accessibility.
7. If evidence is insufficient, ask rather than inventing a new style rule.
